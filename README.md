# 九格日常 — 數獨 Sudoku

一款以原生 HTML、CSS 與 JavaScript 製作的響應式數獨遊戲，無需安裝第三方套件或啟動後端。

## 本機啟動

在此資料夾執行：

```sh
python3 -m http.server 3000
```

瀏覽器開啟 `http://localhost:3000`。

## 遊戲操作

點選空格後，以鍵盤 `1`–`9` 或棋盤下方數字列填數；`← ↑ → ↓` 移動選取格；`N` 切換候選數字筆記；`H` 顯示一格答案；`Backspace` 或 `Delete` 清除。右側亦有筆記、提示、撤銷、暫停、重新開始與新局控制。第三次錯誤輸入會結束當前局；可切換即時錯誤提示與相關格子高亮。

## 專案檔案

- `index.html`：中文遊戲頁面與無障礙標記。
- `styles.css`：響應式版型與視覺設計。
- `sudoku.js`：合法盤面生成、唯一解驗證及難度線索移除。
- `app.js`：棋盤、輸入、計時、設定與遊戲狀態。
- `manus-routes.json`：正式網站頁面路由宣告。
- `dist/`：靜態發佈內容。
